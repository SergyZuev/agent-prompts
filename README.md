# agent-prompts — промты для агентных систем

Рабочие промты для браузерных AI-агентов с заметками по проектированию:
почему правила устроены именно так и какие крайние случаи всплыли
в реальных прогонах.

| Файл | Тип агента | Что показывает |
|---|---|---|
| [01-job-search-browser-agent.md](01-job-search-browser-agent.md) | браузерный агент, многошаговый поиск | декомпозиция на этапы, правила качества данных, верификация источников, структурированный отчёт |

## Принципы

1. **Явная граница действий.** Что агенту можно, что нельзя — отдельным
   блоком, до описания задачи.
2. **Fail-safe вместо догадки.** Если шаг не выполняется как описано —
   агент останавливается и сообщает, а не выбирает «похожий» вариант.
3. **Только данные из источника.** Агент не дописывает того, чего нет
   в исходном тексте, и помечает, что не удалось проверить.
4. **Отчёт как часть задачи.** Формат результата задан заранее, включая
   раздел «что не удалось проверить».
